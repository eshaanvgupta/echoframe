# Changelog

## 1.1.0 — 2026-11-19

First packaged public release of the implemented ECHOFRAME infrastructure platform.

- Nine independently packed TypeScript/ESM packages, CLI and six read-only MCP tools.
- Durable Express/Hono payment recording, safe metadata defaults and opt-in outcome projections.
- Exact payment expectations and explicit Transfer selection; separate execution, attribution, authority, delivery and outcome verdicts.
- Independent evidence/proof verification, trace-aware diagnoses and executable regressions; all 16 deterministic scenarios retained.
- IndexedDB/SQLite persistence, restart recovery, contained exports and optional encrypted portable files.
- Production static frontend with accessible responsive layouts, locally bundled fonts, reduced motion and offline operation.
- Opt-in official Celo Sepolia x402 integration with staged MetaMask review/sign/submit, private server-side facilitator credentials and durable one-purchase gates.
- Genuine owner-approved 0.01 test-USDC evidence, including the original unsupported-header observation and explicitly sourced read-only recovery. Official SDK epoch-valid authorization windows are accepted with bounded remaining validity.
- GitHub project Pages base paths, physical deep-link documents, scoped service-worker caches and meta CSP where response headers cannot be configured.

Evidence/proof schemas remain version 1.0.0. Package, report and diagnosis versions are 1.1.0. This release does not assert npm publication, external adoption, a mainnet purchase, a formal security audit or grant eligibility.
