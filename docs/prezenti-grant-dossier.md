# Prezenti Frontier application dossier

Prepared on 2026-11-19. This dossier records implemented software and an activation plan, not an assertion of grant eligibility, award or independent adoption.

**Problem.** A buyer or builder often cannot distinguish permission to pay, a quote actually accepted, a settled token event, an HTTP response and independently checked work. Timeout/retry ambiguity can trigger duplicate economic actions. Evidence spans merchants, facilitators, chains and returned files, and is difficult to reproduce independently.

**Product and users.** ECHOFRAME is local-first forensic infrastructure for Celo agents, merchant developers, framework maintainers, auditors and mobile buyers. Nine buildable packages, a static responsive PWA, CLI, read-only MCP, persistent journals and 16 deterministic scenarios connect one specific payment flight record to a reproducible regression. No paid API or AI model determines security outcomes.

**Novelty.** The cohesive evidence-to-regression workflow is the contribution. Existing receipts, wallet controls, seller probes, graph analytics and escrow are not claimed as new. The product distinguishes app reports, signatures, RPC observations and reproduced checks and refuses to infer delivery from a transfer.

**Direct Celo benefit.** Runtime chain checks cover Celo 42220 and Sepolia 11142220; strict ERC-20 observations, native x402/MPP profiles, explicit supported ERC-8183 reference reads and optional official Self/ERC-8004 views help Celo builders debug interoperable agent flows. Offline tooling imposes no token or faucet prerequisite.

**Grant cap and terms.** The current [Celo builders page](https://celo.org/builders) and [executed CGP-249](https://github.com/celo-org/governance/blob/main/CGPs/cgp-0249.md) support a Frontier cap of **15,000 USDm**. Proposed request: up to that cap, subject to current program eligibility, funding availability and reviewer agreement. The [Season 3 announcement](https://forum.celo.org/t/prezenti-season-3-is-open-frontier-anchor-and-boost-grants-for-celo/13714) identifies mainnet deployment/verifiable activity requirements. Refresh terms before applying. No eligibility or funding is guaranteed.

**Missing prerequisites.** No consenting ECHOFRAME mainnet payment flow, independent package adoption, external developer feedback session, sponsor/faucet eligibility or funding award has been observed. A static read-only app and public blockchain reads alone may not satisfy associated mainnet activity requirements. Optional identity reads are not ECHOFRAME registrations. This is an infrastructure project; any program exception must be confirmed by the program rather than assumed.

**Optional consenting sponsored integration.** Recruit an existing Celo x402/MPP provider and one independent builder who explicitly consent to recording a real purchase. Independently refresh supported facilitator assets at [x402.celo.org](https://x402.celo.org/), sponsor/faucet eligibility and terms. Obtain user wallet approval for any actual payment and disclose possible gas/economic cost. Record the genuine request, redacted metadata, actual public transaction and deliverable hash; run independent outcome checks and publish only with consent. If sponsorship, eligibility or consent is unavailable, leave the metric unobserved. Never create wash traffic or automatic mainnet writes.

## Eligibility and delivery checklist refreshed for this upgrade

The [official Season 3 announcement](https://forum.celo.org/t/prezenti-season-3-is-open-frontier-anchor-and-boost-grants-for-celo/13714) requests working Celo mainnet infrastructure and associated verifiable activity. This project's public RPC reads satisfy neither deployment nor demand. ERC-8004 registration has an infrastructure exception; obtain program confirmation of ECHOFRAME's classification. Before submission the applicant must supply private contact/delivery information, jurisdiction/entity details, grant-policy agreement and KYC, a Celo L2 payment address, applicable tracking addresses and a maintained KarmaGAP profile; a logo is needed if selected. These applicant-specific items are not fabricated or automatically submitted. Applications close December 29, 2026; funding remains subject to rolling availability and reviewer judgment.
